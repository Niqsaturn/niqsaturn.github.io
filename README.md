# En-Route: Blitzkrieg — Official Homepage

This repository serves the official En-Route: Blitzkrieg landing page at **https://niqsaturn.github.io/**.

The game's source, launcher, release manifests, and original website media remain managed separately in [Niqsaturn/En-Route](https://github.com/Niqsaturn/En-Route). The current homepage intentionally reuses the published `/En-Route/assets/` game captures and trailer while presenting the full site directly at the account's GitHub Pages root.

The currently public Windows download is version **0.2.21** (portable ZIP); 0.2.22 is still undergoing verification. Registration talks to the separate HTTPS En-Route account service. Do not put privileged GM interfaces or backend credentials in this static repository.
